Arquitetura do Sistema

Stack self-hosted em um servidor Ubuntu doméstico, exposto à internet por Cloudflare Tunnel. O servidor é stateless: os dados ficam em um PostgreSQL serverless no Neon.

02 · do browser ao servidor e volta

Fluxo de Request

request-flow.svg
  1. 01

    Usuário acessa lucasaguiar.online

    Request HTTPS sai do browser. :443

  2. 02

    Cloudflare recebe o request

    Termina o TLS, serve cache de CDN e aplica a proteção contra DDoS.

  3. 03

    Tunnel encaminha ao servidor local

    O cloudflared mantém uma conexão de saída com a Cloudflare, sem nenhuma porta aberta no roteador.

  4. 04

    Nginx roteia na porta 80

    A decisão é feita pelo path da URL.

    /api/*

    Node.js :4000
    REST API, com rate limit

    /*

    public/
    Arquivos estáticos

  5. 05

    Node consulta o Neon (apenas em /api)

    Conexão de saída com SSL para o Neon, na porta 5432. A resposta volta ao Node antes de ele responder ao cliente.

    O tunnel não participa desta etapa: é uma conexão direta do servidor para a internet.

  6. 06

    Resposta retorna pelo caminho principal

    Node ou estáticos → Nginx → Tunnel → Cloudflare → Usuário.
